Реализация простейшего однослойного перцептрона.

//22.09

"Взять ли с собой на лицу зонт?".

По погоде решить брать ли с собой на лицу зонт или он не нужен.

Факты.

Есть ли на небе тучи? 1 да, 0 нет.

Передавали ли в прогнозе дождь? 1 да, 0 нет.

Веса.

Тучи на небе. Важно 4 балла.

Прогноз погоды плохой. 2 балла.

Порог смещения примем за 3.

Переменные:

s - решение, сумма фактов и их весов.

x1, x2, ... xn - факты.

w1, w2, ... wn - веса.

b - порог смещения (биас).

Обучаем перцептрон:

тучи на небе, но дождь не обещают: s = 1 > 0 поэтому  взяли зонт, а дождь так и не пошел.

Ответ перцептрона был 1, а должен тогда быть 0, поэтому считаем 0 + (-1) = -1.

Из-за ошибки пересчитываем веса 4 - 1 = 3, новый вес. И пересчитваем биас: b = - 3 -1 = -4.
